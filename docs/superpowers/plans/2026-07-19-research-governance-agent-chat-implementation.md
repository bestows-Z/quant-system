# 真实回测、自动交易治理与 AI 研究聊天实施计划

## 批次 1：数据库与真实回测治理

1. 新增迁移：聊天会话/消息、自动账户归档字段、回测来源字段和必要索引。
2. 物理清理 mock/bootstrap/fixture/synthetic 回测及其结果、成交、权益曲线和关联风险记录。
3. backtest-rpc 增加真实来源持久化校验、单删和批量删除 RPC。
4. gateway-api 增加回测删除接口，验收跨用户隔离、运行中保护和幂等。
5. 修复权益曲线列表顺序、字段契约和前端图表渲染。

## 批次 2：自动账户编辑、归档与研究目标

1. auto-trader-rpc 增加账户编辑、归档、归档列表与状态约束。
2. gateway-api 暴露 PUT/DELETE 接口，不直接访问数据库。
3. 策略生成增加研究目标模板和结构化偏好，后端继续执行白名单 DSL。
4. 前端增加账户编辑、归档确认和新手研究目标模板。

## 批次 3：交割单与 CSV 导出

1. auto-trader-rpc 聚合真实模拟订单、成交和策略决策形成交割单。
2. gateway-api 提供筛选列表和 UTF-8 BOM CSV 导出。
3. 防止 CSV 公式注入并记录导出审计。
4. 前端增加交割单标签、筛选和一键导出。

## 批次 4：内容与策略删除

1. agent-rpc 增加报告单删/批量删除，并解除模型调用报告关联。
2. risk-rpc 增加按 ID、已处理批量删除和高风险确认。
3. strategy-rpc 仅允许删除个人策略，并保护活动引用和系统内置策略。
4. gateway-api、Vue API 和页面增加批量选择、确认、反馈与刷新。

## 批次 5：AI WebSocket 研究聊天

1. agent-rpc 增加聊天会话、消息和只读工具编排 RPC。
2. ws-api 增加 `/ws/agent-chat`，实现 accepted/tool/delta/completed/error 事件。
3. 工具接入行情、K线、指标、盘口、公司公告资讯、持仓、回测和 RAG。
4. 增加连接、频率、单活动请求、取消和日志脱敏控制。
5. Vue 增加会话式聊天页面、证据面板和移动端抽屉。

## 批次 6：图表、导航与 UI 整理

1. TimeshareChart 使用全部可见百分比曲线的联合范围和安全边距。
2. PageContainer 增加统一返回按钮和父级路由规则。
3. 侧栏重排并补齐 AI 聊天、交割单和分析档案入口。
4. 回测、自动交易、风控、策略和分析档案统一筛选栏、批量操作与空状态。

## 批次 7：全量验收

1. `go mod tidy && go test ./... && go build ./...`。
2. Python 全量测试。
3. Vue 类型检查和生产构建。
4. 强制重建受影响 Docker 服务并检查迁移。
5. 扩展 smoke/full acceptance，覆盖删除幂等、真实来源、账户归档、交割单、聊天和图表范围。
6. 浏览器验证桌面及 390px 页面、WebSocket 流和控制台错误。
