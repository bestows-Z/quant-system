# 实时看盘、板块研究与内容生命周期实施计划

设计依据：`docs/superpowers/specs/2026-07-19-realtime-stream-sector-agent-content-lifecycle-design.md`

## 批次 1：计划校正与交易安全基线

1. 更新 `task_plan.md` 中阶段 13、14、15 的真实状态。
2. 为盘口时间解析、交易时段和 3 秒新鲜度添加失败测试。
3. 在 `paper-rpc` 拒绝休市、过期、倒序、非真实和空盘口订单。
4. 前端订单组件展示行情时间、新鲜度和禁用原因。
5. 运行 paper-rpc 测试、Go 编译和接口拒单测试。

## 批次 2：订阅驱动实时流

1. 扩展 ws-api 配置，接入 market-rpc 与 Redis。
2. Hub 维护订阅引用计数和活跃股票集合。
3. 实现按股票共享的 quote/orderbook/timeshare 采集循环。
4. 推送 sequence、quote_time、server_time、latency_ms 和 data_mode。
5. 前端 WebSocket 类型与 StockDetail/Timeshare 增量更新。
6. 验证多客户端共享上游请求、退订停止、倒序消息丢弃和断线重订阅。

## 批次 3：限价续撮与过期撤单

1. paper proto 增加 `MatchPendingBySymbol` 与 `ExpireOrders`。
2. 抽取可复用逐档成交事务，支持累计均价、累计手续费和多次续撮。
3. ws-api 在新盘口后触发按股票续撮，paper-rpc 定时处理到期订单。
4. 撤销剩余买单冻结资金或卖单冻结持仓。
5. 发布成交、部分成交和过期事件。
6. 测试全部成交、部分成交、二次续撮、限价保护、T+1 和资金守恒。

## 批次 4：A 型个股工作台与分时对比

1. 重构 StockDetail 主区，分时/盘口/交易保持同屏。
2. QuickPaperOrder 使用 WebSocket 最新盘口，并在提交前显示二次校验说明。
3. TimeshareChart 支持主标的加三个股票或板块的百分比曲线。
4. 实现股票/板块统一对比搜索、重复禁用和移除。
5. 桌面与移动端分别验证布局、Tooltip、颜色和无横向溢出。

## 批次 5：板块目录、详情、成分股和分时

1. 扩展 feature proto：板块列表、详情、成分股、分时。
2. 新增板块与成分关系表、板块分钟快照表和索引。
3. 行业板块从完整证券主数据生成，概念板块同步真实 Provider 成分。
4. 以真实成分股快照计算覆盖率、涨跌幅、广度、成交额和领涨股。
5. 新增板块详情页、排序、成分股实时订阅和个股跳转。
6. 验证全部行业可见、成分关系可追溯、低覆盖率不输出伪精度。

## 批次 6：Agent 公告资讯证据

1. MarketTool 并行获取公司资料、公告和资讯。
2. 公告资讯按 URL/标题/时间去重，限制 20 条并按时间衰减。
3. Agent 结构化上下文与报告增加公告资讯章节和来源状态。
4. 报告存档保存公告/资讯证据 ID、URL、来源和时间。
5. 系统研究库补充公告事件分类方法并同步 Qdrant。
6. 测试有模型和无模型报告均包含真实证据或明确不可用状态。

## 批次 7：通知、文档和知识库删除

1. gateway 接通已有通知单删 RPC，增加删除已读和清空 RPC。
2. RAG proto 增加删除文档和知识库。
3. 实现用户归属、系统公共知识保护、MySQL 事务和 Qdrant 点删除。
4. Qdrant 删除失败写清理任务并重试，查询立即排除软删除文档。
5. 前端增加单删、批量删除、危险确认和幂等状态。
6. 验证跨用户拒绝、重复删除和向量数量变化。

## 批次 8：模型统计布局与自动策略收尾

1. AI 模型统计块改为稳定尺寸 Flex 布局。
2. 自动策略保存回测/样本外评估并支持晋级审计。
3. 自动账户支持多策略权重和总风险预算。
4. 收盘评估调度与交易时段增量运行分离。
5. 验证无模型量化降级、AI DSL 白名单和模拟账户资金约束。

## 批次 9：全量验收

1. Python 全量测试。
2. Go `go mod tidy`、`go test ./...`、`go build ./...`。
3. Vue 类型检查和生产构建。
4. Docker Compose 全量启动和健康检查。
5. 端到端验收扩展到实时流、删除、板块、Agent 证据和自动交易。
6. 浏览器验证 `1440x900` 与 `390x844`，检查控制台、网络和横向溢出。
7. 扫描最近日志中的 502、panic、fatal、密钥和 JWT 泄漏。

## 完成定义

- 所有新增接口使用真实数据或明确不可用状态，不返回 mock。
- 所有测试、构建、容器和浏览器验收通过。
- `task_plan.md`、`progress.md`、`findings.md`、API、数据库和 WebSocket 文档同步更新。
