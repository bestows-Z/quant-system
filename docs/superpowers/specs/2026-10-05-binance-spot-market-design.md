# 币安现货公开行情工作台设计

## 范围

本批只完成一项可独立验收的功能：在现有平台中查看币安现货的真实公开行情、交易对规则和历史 K 线。它是后续数字资产模拟交易与回测的数据入口，不接交易密钥，不下真实订单，也不把股票的 T+1、100 股单位等约束套用到现货。

## 取舍

候选方案有三个：直接由浏览器调用币安、由 Go Gateway 调币安、由 Python 数据服务调币安再通过 Gateway 转发。选择第三种：复用平台已有“数据源在 Python、认证与入口在 Gateway”的分层。前两种虽然省文件，但分别暴露前端跨域/来源控制和混淆 Gateway 职责的问题。

## 用户流程与页面

侧栏“市场洞察”增加“数字资产现货”。页面沿用平台导航与中文文案，主内容参考币安的深色交易终端：克制的石墨黑、金色交互强调、等宽价格、紧凑行情头部。桌面为交易对列表与主图两栏；手机先看交易对与报价，再看图和规则，不能整页横向溢出。可切换 BTC/USDT、ETH/USDT、BNB/USDT，以及 1 小时、4 小时、1 日 K 线。明确标注来源、UTC K 线口径、最近更新时刻和“只读行情；尚未接入模拟订单”。不得显示假的账户余额或买卖按钮。

## 数据链路

Python `BinanceSpotMarketProvider` 仅请求币安官方 `data-api.binance.vision` 公开接口：`exchangeInfo`、`ticker/24hr`、`klines`。服务端固定域名与路径，不接受用户自定义 URL；交易对和周期均白名单；HTTPS 请求设置超时；检查 HTTP 状态和返回结构；最多返回 240 根已收盘 K 线，正在形成的 K 线不进入研究序列。接口返回原始来源、`data_mode=real`、时间戳、交易对状态，以及 `PRICE_FILTER`、`LOT_SIZE`、`MIN_NOTIONAL`/`NOTIONAL` 字段。任何请求失败都返回明确不可用状态，不降级到模拟行情。

Go Gateway 新增只读、需登录的 `/api/crypto/spot/market`，向固定 Python 内网地址转发经过白名单校验的查询参数；不透传外部 URL，也不记录请求密钥。前端单独的数据类型和 API 文件负责渲染。

## 错误与边界

- Binance 公共域名不可用、451、429、超时时显示实际错误与重试入口；不能使用随机或上次未标注的报价。
- 交易对暂停时保留行情，但显示交易状态，不给出可交易结论。
- 所有报价单位是 USDT；成交量注明基础资产/报价资产；价格精度来自交易所规则，不固定两位小数。
- 数字资产交易、账户接入、现货模拟撮合、多交易所支持和 AI 策略生成不属于本项功能，写入后续路线，避免用一个行情页冒充完整交易系统。

## 验收

有固定样本的 Python 单测覆盖映射、未收盘 K 线排除、非法交易对/周期、源失败。Go 测试覆盖参数校验与来源错误。Vue 生产构建通过。浏览器桌面和窄屏验证真实数据、切换、故障态、控制台和横向溢出。README 记录功能范围与数据来源。
