# 真实回测、自动交易治理与 AI 研究聊天设计

## 1. 目标

本阶段完善研究数据治理、自动模拟交易账户生命周期、AI 研究聊天和前端导航体验。系统仍只进行数据分析和模拟交易，不连接券商，不输出确定性投资建议。

验收目标：

- 回测中心只展示来源可追溯的真实行情回测，历史 mock/bootstrap 回测物理清理。
- 回测记录、分析档案、风控记录和个人策略支持安全的单条及批量删除。
- 自动交易账户可以编辑和归档，历史策略、决策、订单、成交与交割单不可被账户归档破坏。
- AI 聊天使用 WebSocket 流式通信，保存会话，并通过只读工具查询真实研究数据。
- 回测权益曲线、分时对比范围、导航和返回路径可正常使用。
- 自动交易交割单可筛选并导出 CSV。

## 2. 工程边界

- 不新增集中式“大服务”，沿用现有 go-zero 微服务边界。
- `gateway-api` 不直接访问数据库，只负责 HTTP 契约、鉴权和 RPC 编排。
- `ws-api` 负责 AI 聊天连接和流式事件传输，业务消息与会话由 `agent-rpc` 持久化。
- AI 聊天工具严格只读，不能创建订单、修改账户、启停自动交易或删除数据。
- 删除均校验当前用户；系统内置策略和公共知识内容不允许普通用户删除。
- 免费公网行情只作为研究数据，不声称具备交易所授权的毫秒级行情质量。

## 3. 真实回测治理

### 3.1 真实数据判定

成功回测必须同时满足：

- Python 回测响应包含非空 `source`。
- `data_mode` 必须为 `real`。
- 来源不得包含 `mock`、`bootstrap`、`fixture` 或 `synthetic`。
- 回测任务保存策略参数、数据来源、数据模式和行情覆盖证据。

不满足条件时任务保存为失败状态，不创建成功结果、成交或权益曲线。现有 mock/bootstrap 任务及其结果、成交、权益曲线和关联回测风险记录通过迁移脚本物理删除。

### 3.2 删除

- 单条删除：仅允许删除当前用户拥有且非运行中的任务。
- 批量删除：支持明确 ID 列表，也支持清理失败任务；不提供无确认的全库删除。
- 删除事务按外键依赖顺序清理风险记录、权益曲线、成交、结果和任务。
- 重复删除返回幂等成功及 `already_deleted=true`。

### 3.3 权益曲线

权益曲线接口返回按日期升序的数据，并统一使用 `trade_date`、`total_asset`、`cash`、`market_value`、`drawdown`。前端只在至少两个有效点时绘制曲线；单点或空数据展示明确原因。图表容器使用稳定高度并监听尺寸变化。

## 4. 自动交易账户与交割单

### 4.1 生命周期

- 账户状态为 `PAUSED` 时允许编辑名称和风控参数。
- `RUNNING` 状态禁止编辑或归档，必须先暂停。
- 删除采用归档语义：设置 `archived_at` 和 `status=ARCHIVED`，默认列表不返回。
- 归档保留策略版本、运行批次、决策、模拟订单、成交和审计记录。
- 重复归档幂等成功。

### 4.2 AI 生成研究目标

策略生成表单增加必填的“AI 生成研究目标”，包含：

- 自由文本目标。
- 面向新手的示例模板：低回撤趋势、均线趋势、量价突破、超卖反弹研究。
- 风险偏好、持有周期、最大可接受回撤和换手偏好仍由结构化字段控制，AI 不能绕过账户风控。

AI 只从现有白名单策略 DSL 中选择基础策略和参数。未配置模型时使用本地规则生成同结构候选，并明确标记生成方式。

### 4.3 交割单

交割单基于真实保存的模拟成交、订单和自动策略决策生成，不创建演示记录。每条记录包含成交时间、股票、方向、委托类型、委托价、成交价、成交数量、成交额、手续费、滑点、策略版本、决策原因、行情来源和订单编号。

导出接口按账户、日期范围和股票过滤生成 UTF-8 BOM CSV，列名使用中文，金额与数量保持机器可读数值。导出动作写审计日志，但不修改交易数据。

## 5. AI 研究聊天

### 5.1 会话模型

MySQL 新增：

- `agent_chat_sessions`：用户、标题、状态、最后消息时间、创建/更新时间、软删除时间。
- `agent_chat_messages`：会话、角色、内容、状态、模型信息、Token、延迟、引用和工具调用 JSON、创建时间。

支持会话列表、创建、重命名、删除和清空消息。删除会话后默认查询不可见；消息按会话所有权校验。

### 5.2 WebSocket 协议

路径：`/ws/agent-chat?token={jwt}`。

客户端消息：

```json
{"type":"chat.ask","request_id":"uuid","session_id":1,"content":"分析中国巨石近期量价变化"}
```

服务端事件：

- `chat.accepted`：请求已接收。
- `chat.tool.started`：开始调用只读工具。
- `chat.tool.completed`：工具完成，包含来源摘要。
- `chat.delta`：增量回答文本。
- `chat.completed`：最终消息、引用、模型与用量。
- `chat.error`：中文错误码、信息和 trace_id。

同一连接最多一个活动生成任务；同一用户设置连接和频率上限。断线取消当前下游调用，已经落库的用户消息保留，助手消息标记为失败，可重新发送。

### 5.3 只读工具

首批工具：

- 股票搜索与详情。
- 实时行情、五档盘口和分时。
- 日 K、成交量、MA、MACD、RSI、BOLL。
- 压力位、支撑位、资金流。
- 公司资料、公告和财经资讯。
- 用户真实持仓及其最近分析。
- 用户回测结果和交易明细。
- RAG 知识库检索。

工具结果必须保留 `source`、`data_mode`、行情时间和错误状态。真实源不可用时明确说明，不补造数值。

## 6. 内容治理

### 6.1 分析档案

Agent 分析报告支持单条删除和按 ID 批量删除。删除报告同时解除模型调用记录的报告关联，但保留模型用量审计。

### 6.2 风控记录

风控记录支持单条、已处理和 ID 列表批量删除。未处理的高风险或极端风险记录批量删除时需要显式确认参数。删除不改变历史模拟订单和成交。

### 6.3 个人策略

只有 `user_id` 属于当前用户的个人策略可以删除。内置策略不允许删除。被运行中回测、自动交易晋级版本或活动任务引用时返回冲突错误；无活动引用时软删除策略，历史信号继续保留策略快照字段。

## 7. 前端信息架构与交互

- 顶部页面容器统一提供返回按钮；有明确父页面时返回父路由，否则调用浏览器后退。
- 侧栏分为市场洞察、量化研究、组合与交易、AI 与知识、运营中心和系统状态。
- 新增“AI 研究助手”独立页面：左侧会话列表、中央消息流、右侧可折叠证据和工具调用区；移动端改为抽屉。
- 回测中心增加来源标签、批量选择、删除、权益曲线状态和查看详情入口。
- 自动交易页面将账户、策略、运行、决策和交割单拆成标签视图，账户编辑/归档使用对话框。
- 分析档案、风控和策略页统一批量选择、删除确认、空状态和刷新反馈。

## 8. 分时对比修复

所有对比曲线先转换为相对各自昨收的百分比，再计算全部可见曲线的联合最小值和最大值。Y 轴范围包含至少 0.5 个百分点或实际范围 12% 的上下边距，并始终包含 0 轴。对比标的涨跌超过主股票时，主曲线和对比曲线都不得被裁切。

## 9. 错误处理与安全

- 所有 REST 接口继续返回 `{code,message,data,trace_id}`。
- WebSocket 错误包含稳定错误码和 trace_id，不发送后端堆栈。
- 删除、账户编辑、导出和聊天工具调用写访问或审计日志。
- CSV 导出防止公式注入，文本以 `= + - @` 开头时进行转义。
- 聊天工具参数由后端 schema 校验，模型输出不能构造任意 URL、SQL 或 RPC 方法。
- WebSocket 日志不得记录 JWT 或完整聊天敏感内容。

## 10. 测试与验收

- Go：领域单测、RPC 编译、`go test ./...`、`go build ./...`。
- Python：真实回测来源与参数透传回归测试。
- Vue：类型检查、生产构建、图表空/单点/多点测试。
- Docker：强制重建受影响服务，检查健康状态和错误日志。
- 端到端：真实回测、删除幂等、账户暂停编辑归档、策略引用保护、聊天工具和流式事件、交割单导出、分时联合范围。
- 浏览器：桌面和 390px 检查回测、自动交易、AI 聊天、风控、策略、分析档案和返回导航；不得出现横向页面溢出或控制台错误。

## 11. 明确不在本阶段实现

- AI 聊天直接下单或启停自动交易。
- 真实券商账户与实盘交割单。
- 任意用户代码策略执行。
- 未授权 Level-2 行情或交易所级毫秒延迟承诺。
