# 模拟交易与自动策略

本系统不连接券商，不发送真实委托。所有买卖、成交、持仓和收益均属于研究用途的模拟交易，不构成投资建议。

## 人工模拟下单

- A 股买入数量按 100 股整数倍校验。
- 买入增加 `today_buy_volume`，当日不增加可卖数量；下一交易日才释放，落实 T+1。
- 市价单和限价单均由 paper-rpc 读取 market-rpc 的五档快照，不接受前端自行提交的“最新价”作为成交依据。
- 交易时段要求盘口时间不超过 3 秒；过期、缺失或非真实盘口会拒绝成交并给出中文原因。
- 买单从卖一向上、卖单从买一向下逐档撮合。深度不足时保留剩余数量为部分成交订单，后续盘口更新继续撮合。
- 收盘后撤销未成交剩余数量，释放冻结资金或持仓；已经成交的部分不回滚。
- 交易日判断覆盖周末与 2026 年上交所公布休市日；系统不会在集合竞价或 14:57 后的收盘竞价阶段使用连续竞价撮合规则。跨年度部署前应同步下一年度官方日历。

## 自动策略治理

策略版本生命周期为 `SHADOW -> PROMOTED -> RETIRED`。AI 只能从内置白名单算法中选择参数并生成解释，不能上传或执行任意代码。

1. 生成影子策略。
2. 通过 backtest-rpc 对真实历史 K 线执行多标的回测。
3. 保存收益、回撤、胜率、交易次数和数据覆盖证据。
4. 只有评估通过且用户人工确认的版本才能晋级。
5. 交易时段按分钟运行量化规则；LLM 不进入低延迟撮合路径。
6. 风控通过后，使用不超过 3 秒的真实五档盘口创建模拟委托。

账户风险边界包括单票仓位、组合总仓位、每日最大亏损、最低信号分和最大持股数。候选扫描范围不因最大持股数而截断，但只有满足全部边界的信号可以形成模拟委托。

当前一个自动账户只允许一个晋级执行版本。多策略风险预算、权重再平衡和组合级归因将在下一阶段实现，在此之前不声称具备多策略实盘级分配能力。

## 行情边界

免费公网行情适用于秒级研究与模拟，不等同于交易所授权行情。系统通过服务端 WebSocket 生产者、Redis 最新快照和时间戳校验减少页面与撮合价格不一致，但不能承诺完整 Level-2 深度或稳定毫秒延迟。
